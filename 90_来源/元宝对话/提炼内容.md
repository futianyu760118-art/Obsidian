## 📌 视频内容提炼：AI 视频学习插件（开源项目）

### 一、核心功能概览

这是一个 **Chrome 浏览器插件**（开源项目），主打「沉浸式 AI 辅助视频学习」，核心功能模块如下：

| 模块 | 功能说明 |
| --- | --- |
| **Panel 字稿面板** | 展示视频字幕/文稿，支持 **英文 / 中文 / 翻译版 / 双语对照** 多种模式切换 |
| **AI 上下文讲解** | 选中任意词语、短语、句子甚至视频片段 → 一键触发 AI 讲解，基于上下文用小白能懂的方式解释概念 |
| **读书岛（快速浏览）** | 结构化展示视频内容大纲，点击对应时间节点即可跳转播放，方便快速定位 |
| **全文导出** | 支持 **Copy 复制全文**，或 **Export 导出 TXT 文档**（含视频标题、描述等元数据），方便二次加工（如改写成博客） |
| **笔记系统（Notes Tab）** | 所有笔记自动记录在右侧 Notes 面板，支持：一键复制笔记内容、一键复制视频时间戳、一键重新播放关联视频片段 |
| **历史记录** | 可查看当前视频和历史视频的学习记录 |

---

### 二、安装步骤（小白友好，无需编程）

> 项目前端设计极简，全程 **不到 10 分钟** 即可搞定。

1. **下载项目**：进入 GitHub 页面 → 点击 `Code` → `Download ZIP` → 解压文件夹
2. **打开 Chrome 扩展管理**：浏览器右上角三个点 → `Extensions` → `Manage Extensions`
3. **开启开发者模式**：右上角打开 `Developer mode`
4. **加载插件**：左上角 `More Actions` → `Load unpacked` → 选择解压后的项目文件夹
5. **完成安装**：插件自动加载，按引导完成设置

> 💡 **小白提示**：如果你完全不懂操作，直接把 GitHub 链接发给 AI（如 Copilot、豆包等），它会一步步教你完成。
