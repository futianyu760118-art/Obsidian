# 收件箱

这里是所有新想法、临时摘录、待判断文件和未整理内容的入口。

## 整理流程

```text
捕获 → 判断四维 → 判断类型 → 建立双链 → 迁移或归档
```

## 判断问题

- 这是关于我、家、公司还是社会？
- 它是一个长期领域、具体项目、会议记录、资料、决策还是普通笔记？
- 它是否需要下一步行动？
- 它是否有原始来源需要保留？

## 规则

- 不要求刚记录时就分类正确。
- 不确定的内容先留在这里，每周集中整理。
- 原始对话或文件放入 `90_来源`，不要覆盖原文。
- 整理完成后，为笔记补充 `dimension`、`type` 和 `status` 属性。
