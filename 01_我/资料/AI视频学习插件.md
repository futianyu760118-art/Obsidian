# AI 视频学习插件

## 一句话概括

一个面向视频学习场景的 Chrome 开源扩展：把字幕、翻译、上下文解释、时间节点、笔记和导出能力放在同一套学习面板里。

## 核心功能

| 模块 | 规范化描述 |
| --- | --- |
| 字稿面板 | 展示视频字幕/文稿，支持英文、中文、翻译版和双语对照。 |
| 上下文讲解 | 选中词语、短语、句子或视频片段，让 AI 结合上下文用小白能理解的方式解释。 |
| 快速浏览 | 展示内容结构和时间节点，点击节点即可跳转到视频对应位置。 |
| 复制与导出 | 复制全文，或导出包含标题、描述等元数据的 TXT，便于改写成博客或其他内容。 |
| Notes | 保存笔记，支持复制笔记、复制时间戳、重新播放关联片段。 |
| 历史记录 | 查看当前视频和历史视频的学习记录。 |

## 对话中整理出的使用流程

1. 从 GitHub 下载项目 ZIP 并解压。
2. 打开 Chrome 扩展管理页，开启开发者模式。
3. 选择「Load unpacked/加载已解压的扩展程序」，指向项目目录。
4. 按项目引导配置两个 API。
5. 打开视频，使用字幕、翻译、上下文解释、时间跳转和 Notes。
6. 需要二次创作时复制或导出完整文稿。

## 适用场景

- 英文技术视频学习：双语对照和即时解释降低理解成本。
- 内容二次创作：把字幕和元数据导出后改写成博客、摘要或脚本。
- 学习回顾：通过笔记时间戳快速回到原视频片段。
- 开源项目定制：根据个人学习流程增加模板或功能。
